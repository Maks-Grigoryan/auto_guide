# Авто Армения — мобильное приложение

Flutter-клиент агрегатора магазинов автозапчастей и автосервисов. Подробные инструкции по запуску, конфигурации API/MapKit, тестированию и release-сборке находятся в корневом [`README.md`](../README.md).

Минимальный запуск из этого каталога:

```powershell
flutter pub get
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:3000 --dart-define=MAPKIT_API_KEY=your-key
```
