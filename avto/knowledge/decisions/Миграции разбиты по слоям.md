# Миграции разбиты по слоям

**Решение:** node-pg-migrate, отдельные миграции по слоям, а не одна baseline:
`001_extensions` (postgis, pg_trgm) → `002_tables_and_indexes` → `003_search_functions` → `004_seed`.

**Почему:** чище версионируется и ревьюится.

**Как применять:** `npm run migrate:up` (путь `-m ../db/migrations`, см. [[migrate up игнорировал путь конфига]]).
