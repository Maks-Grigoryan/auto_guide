# Каталог импортируется уже в Phase 1

**Решение:** полный импорт vPIC + CIS-марок выполнен уже в Phase 1 (требование CAT-01 перенесено из Phase 2).

**Почему:** критерий успеха Phase 1 уже требует, чтобы CIS-марки были searchable; чище импортировать каталог сразу.

**Следствие:** Phase 2 сужается до CAT-02 (API справочников `/makes`/`/models`/`/generations` с кэшем) + селектор авто (SEL).
