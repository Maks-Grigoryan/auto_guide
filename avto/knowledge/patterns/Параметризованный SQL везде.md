# Параметризованный SQL везде

Любой SQL — через параметры (`$1, $2, ...`), без интерполяции строк. Касается и сервиса (`search_parts($1..$7)`), и сид-импорта (`import_catalog.mjs`). Закрывает SQL-инъекции (угрозы T-01-04/06/09).

На входе API — DTO `class-validator` + глобальный `ValidationPipe({transform, whitelist})`. Ошибки — через `SafeExceptionFilter` (только `{error, message}`, без стектрейсов).
