# Каталог авто из NHTSA vPIC — только США

NHTSA vPIC — бесплатный источник марок/моделей, но покрывает **только рынок США**. Марки СНГ (ВАЗ/Lada, ГАЗ, УАЗ, Москвич, ЗАЗ) там отсутствуют.

Решение: vPIC для топ-марок + ручной `db/seed/cis_makes.csv` для СНГ. Импорт — `scripts/import_catalog.mjs` (идемпотентные upsert через pg.Pool), есть оффлайн-fallback `db/seed/vpic_makes.csv`.

Реализовано уже в Phase 1 — см. [[Каталог импортируется уже в Phase 1]].
