# 🏠 Авто-агрегатор — База знаний

Мобильный агрегатор автосервисов (СТО) и магазинов запчастей для Армении/СНГ.
Стек: Flutter + NestJS + PostgreSQL/PostGIS, карты Яндекс, валюта AMD.

> Источник истины по проекту: `docs/PROJECT-BRIEF.md` и `.planning/` в корне репозитория.

## Знания
- Интеграции: [[Yandex MapKit — официальный пакет]], [[Каталог авто из NHTSA vPIC — только США]]
- Решения: [[MVP — это только геопоиск]], [[pg.Pool вместо ORM для гео]], [[Каталог импортируется уже в Phase 1]], [[Миграции разбиты по слоям]], [[Авторизация отложена в v2]]
- Паттерны: [[ST_DWithin в WHERE, ST_Distance в SELECT]], [[part_fitments NULL означает всю марку]], [[search_parts отдаёт одну строку на продавца]], [[Параметризованный SQL везде]], [[Координаты PostGIS — сначала долгота]]
- Баги: [[migrate up игнорировал путь конфига]], [[Dockerfile context не видел db migrations]], [[EXPLAIN в FROM невалиден в PL pgSQL]]
- Бизнес: [[Доступность для пожилых — это дифференциатор]], [[Цены в AMD]]
